1. 三个 M1 刚验收角色的 high/lod1/bootstrap 合计 **24,082,664 B**，单这一项已占 `public/models` 目标的 97.77%。删除未部署角色母版会制造虚假仓库收益，重压角色则必须整套重跑 M1 三角色门禁，本批按“非必要不动”保留。

## 5. 统一 post-conversion 门禁矩阵

固定工具为 `gltf-validator 2.0.0-dev.3.10`。门禁不是只查文件头：每个唯一 KTX2 都通过项目 Basis transcoder解码为 RGBA8，再按实际 glTF material slot 识别 BaseColor、Normal、AO；字节数与 SHA-256 同时冻结。

| 项目 | 最终值 | 硬门禁 |
|---|---:|---:|
| GLB | 36 | 全覆盖 |
| Validator Error | **0** | =0 |
| standalone KTX2 | 25 | 全覆盖 |
| 唯一 KTX2 payload | 59 | 全部解码 |
| KTX2 解码失败 | **0** | =0 |
| BaseColor 最低 RGB stddev | **8.1659** | ≥8 |
| Normal 最低 RGB stddev | **49.5346** | ≥4 |
| AO(R) 最低 stddev | **3.2382** | ≥3 |
| stddev 失败 | **0** | =0 |

Validator 原始 Warning 511 / Info 401 保留在逐 GLB 报告，不伪装成 Error：主要为该固定版 Validator 对 Meshopt/KTX2 扩展的不识别提示、KTX2 MIME 枚举提示、gltfpack 量化 wrapper 的 skinned-node 提示、运行时生成 tangent 提示与外部 URI 信息；Error 总数真实为 0。

统一报告：`art-source/reports/runtime-asset-gate.json`。一条命令全量复验：

```bash
npm run art:runtime-gate:check
```

该命令由 `tests/runtime-asset-gate.test.mjs` 接入 `npm test`，报告漂移、KTX2 解码失败、stddev 不足、GLB 字节/SHA 漂移或 Validator Error 都会使测试失败。

## 6. 单点版本与 QA 健壮性

所有应用侧 model/KTX2 请求统一经过：

```text
ASSET_VERSION = "m2-20260829"
versionRuntimeAsset(pathname)
```

Basis transcoder本身保持内容稳定 URL；GLB 内部的外部 KTX2 已用 SHA-256 文件名内容寻址，不再叠加散落的人造 v1…v32。

QA 非法输入实测合同：

```text
input.chaserHeading = "toPlayer"
=> { ok:false, error:"QA scenario chaserHeading must be a finite { x, y } point." }
```

同类拒绝覆盖 player/chaser 的 null、NaN/Infinity 坐标以及非有限/负 spawn delay。验证发生在 `new GameSimulation(...)` 之前，非法调用只返回错误，不替换当前 simulation，也不会再触发 “AI evidence observer must have finite public position and heading” 全屏崩溃。

## 7. 回归—修复循环

1. 首次 locker 重导只有几何没有 6 段 door action：定位为已保存母版 action 未挂 NLA；导出前临时重建 NLA，最终 6/6 clip 完整。
2. locker UV 8-bit 候选虽更小，但 gltfpack 报 14% UV error；立即打回，最终采用 Position 12-bit + UV 10-bit，仍把 GLB 降到 681,996 B。
3. 第一版统一门禁真实扫出 11 个旧遗漏：PaintedWall BaseColor 6.5814、6 张 AO 低于 3、4 张 mirror roughness 被误当 AO。修复语义分类后，不降低阈值；从制作源增强墙面细节、从真实 cavity 重建 AO、补足深色工厂镜架粉末涂层，最终最低值均通过。
4. 曾尝试只把 Grass ORM 改 ETC1S，虽能缩小体积且解码门禁通过，但完整回归发现它违反既有“Normal/ORM 必须 UASTC”合同，立即打回；最终保持 UASTC，仅对其采用 quality 4、256px 分级，runtime KTX2 为 **23,911,705 B**，既通过旧 24,000,000 B 门禁也保留视觉阈值。
5. 6 MiB release gate 初次为 6,315,148 B，超 23,692 B；没有放宽门槛，继续安全量化 locker，最终 6,209,054 B。
6. 浏览器缓存曾命中同版本旧 KTX2；统一版本最终冻结为 `m2-20260829`，清 clean build/production server 后重拍六关，console 0。
